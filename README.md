 BloomVote

BloomVote is a modern Quiz & Polling Platform built to make interaction fun, simple, and engaging.
Users can create quizzes, launch polls, share them with others, and view responses in real time.

This project was built as my first full-stack application and became a huge learning journey in backend development, authentication, databases, deployment, and scalable application structure.
---
🚀 Features
📝 Create custom quizzes and polls
📊 Real-time voting and response tracking
🔐 User authentication & authorization
📱 Responsive modern UI
⚡ Fast and smooth user experience
📈 Poll analytics and results
🎯 Share quizzes and polls with anyone
🧠 Interactive question management

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/chirag878/bloomvote.git
2️⃣ Navigate to the project
cd bloomvote
3️⃣ Install dependencies
Frontend
cd client
npm install
Backend
cd server
npm install
🔑 Environment Variables

Create a .env file inside the server folder.

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLIENT_URL=your_frontend_url
▶️ Run the Project
Start Backend
npm run dev
Start Frontend
npm run dev
